## Authorship Designations & Roles

- **Co-First Authorship (Equal Contribution):**
  **Md. Mahbubur Rahman** and **Siam Mridha** contributed equally to this work as co-first authors. They jointly conceived the research framework, designed the two-stage hierarchical neural network topology (LeafCareNet), authored the offline knowledge base and mobile application architecture, conducted the multi-phase cross-domain validation, and drafted the manuscript.

## Distinction Between Academic Authorship and Git Commit Metrics

Academic research authorship reflects scientific conceptualization, algorithmic innovation, experimental execution, statistical validation, and scholarly writing as published in peer-reviewed venues. GitHub repository commit histories, issue trackers, and pull request contributor counts reflect platform-specific code staging and do not alter or supersede the official academic authorship order established above.
